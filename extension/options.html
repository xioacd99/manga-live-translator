本地 OCR 与翻译设置

开发预览版。先配置本机 OCR，再按需配置远程文本翻译。只准备本地识别结果无需大语言模型密钥。

1. 本机 OCR 服务

将图片像素发送到这台电脑上的 PaddleOCR / RT-DETR 服务。服务须单独安装；自动管理模式由扩展在点击启用时启动，关闭最后一个普通浏览器窗口时停止。手动模式由你自行运行；不会把图片上传给 DeepSeek 或 OpenAI。模型下载由本机服务管理，需要在弹窗主动开始。

本机服务连接

手动服务不会被扩展关闭。自动管理须先按安装指南注册 Native Messaging 宿主，再授权本机通信权限。

Chrome 的回环主机权限覆盖该地址的所有端口；手动模式只访问保存的具体端口；自动管理只访问宿主新分配的临时端口。令牌和图片不会转发到页面脚本。



2. 远程文本翻译（可选）


翻译时只发送识别文本、你填入的上下文和术语表，以及翻译配置。API 调用可能产生费用；取消或超时不代表已发送的请求不会计费。失败不会自动重试。


文本翻译提供方


固定地址：https://api.deepseek.com/chat/completions




默认使用 DeepSeek V4.1 Flash，实际 API 模型名为 deepseek-flash。使用 JSON Object 输出并在本地校验全部区域 ID；项目未进行真实付费 API 验证。










两类密钥只保存在扩展受信任的会话存储中，不同步或主动写入持久存储。自动管理模式只持久保存启动方式、阅读方向和本机图片授权，不保存服务令牌、端口或漫画。重启浏览器会清除远程密钥、手动服务令牌与阅读缓存；本机下载的模型文件独立保留。设备遭入侵时，浏览器扩展无法保证密钥安全。无痕模式不可用。
