本地 OCR 与翻译设置

开发预览版。先配置本机 OCR，再按需配置远程文本翻译。只准备本地识别结果无需大语言模型密钥。

1. 本机 OCR 服务

将图片像素发送到这台电脑上的 PaddleOCR / RT-DETR 服务。服务须单独安装并运行；不会把图片上传给 DeepSeek 或 OpenAI。模型下载由本机服务管理，需要在弹窗主动开始。

本机服务连接

Chrome 的回环主机权限覆盖该地址的所有端口；扩展只访问你保存的具体端口。令牌和图片不会转发到页面脚本。



2. 远程文本翻译（可选）


翻译时只发送识别文本、你填入的上下文和术语表，以及翻译配置。API 调用可能产生费用；取消或超时不代表已发送的请求不会计费。失败不会自动重试。


文本翻译提供方


固定地址：https://api.deepseek.com/chat/completions




默认使用 DeepSeek V4.1 Flash，实际 API 模型名为 deepseek-flash。使用 JSON Object 输出并在本地校验全部区域 ID；项目未进行真实付费 API 验证。










两类密钥只保存在扩展受信任的会话存储中，不同步或主动写入持久存储。重启浏览器会清除密钥与阅读缓存；本机下载的模型文件独立保留。设备遭入侵时，浏览器扩展无法保证密钥安全。无痕模式不可用。
