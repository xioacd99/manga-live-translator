# 方法与比较边界

## 输入和标注

使用此前冻结的同10张历史英文漫画原图及人工标注；输入按文件SHA256核验。GT SHA256为 `984017f90ce822edb0c480207ed29ec8ec5ded587ba37f7ec40b3eb35e22753f`。71个目标中67个明确文本区域参与OCR，总计2215字符、522英文词；4个不确定目标不评分。部分页只有部分区域标注，不能代表全页全部文字或现代英译漫画。

没有依据新模型答案修改GT、选择分辨率或重新转写。测试不发送图片给第三方，不使用用户电脑，不调用付费模型。公开报告仅包含来源/哈希、参数、聚合与逐图统计；不包含原图、完整GT或OCR全文。

## 覆盖与控制变量

- v6 tiny/small/medium检测器×识别器3×3组合：固定目标短边2048、长边cap4096；共同单线程运行及已冻结检测敏感参数。
- medium分辨率：1024/1536/2048/2560，其他参数固定。另保留原Global2000/Det min736缩放＋敏感参数一组，隔离与旧默认参数的差异。
- 官方v5 server：单独核对模型YAML、字典和缩放/归一化；采用相同原图与计时框架，不能以统一文件名掩盖不同组件所需预处理。
- 英文专用与Latin：各自正确字典/语言路由，固定同一个v6 small检测器再比较识别分支。不同导出文件不是不同训练型号。

所有新增组先完整单遍覆盖，不按成绩挑选赢家补跑。分组、顺序和安全门限在执行前固定。新runner先以small2048对全部10图桥接，与此前对应预测的框及文字完全一致才进入正式矩阵。

## 图像预处理不能只看检测器shape

目标缩放比例为 `min(short/minSide, 4096/maxSide)`。长边cap可能使实际短边低于目标；不能称“至少2048”。common组先在外层以INTER_LINEAR缩放图像，这张图同时供检测及识别裁框使用，检测器再进行32倍数取整。保留基线的padding/坐标回映射，避免检测看高分辨率、识别却仍从原图裁框的隐性差异。

server默认缩放适配组单独采用官方resize_long的type2规则：长边目标960后双边向上取128倍数；识别从对应原图裁框。它保留共同legacy分类器等Rapid桥接组件，**不是完整官方PaddleX逐位等价测试**。server common组使用共同外层2048，检测内部保留其所需归一化与DB规则；混搭每个组件使用自己的字典和输入配置，不把server字典套给v6。

## 评分

复用 `score.py --wer --text-order line-column-overlap-v2`。预测仅按几何重叠归属人工目标，每个预测最多归属一次；不依据文字相似度选择正确答案。采用NFKC并移除Unicode空白，保留大小写与标点；CER=(替换+删除+插入)/参考字符数，同时给WER及去标点CER。

字符删除D、目标无识别输出数和没有归属原始检测行的目标数，可说明端到端遗漏，但**不等于全页检测mAP或真正气泡检测召回率**。检测行与人工段落目标粒度不一致，不能伪造IoU precision/recall。错误可能来自定位、裁框、识别或阅读顺序，主CER不是纯识别器已知正确裁剪的准确率。

资源失败或超时后，原始已完成输出保留；另外生成完整10图身份清单，缺页记空输出与失败原因。主评分始终保留完整GT分母，不以成功子集隐藏失败。图表只把全部完成且经独立哈希配对复核的组作为有效比较点；若展示失败组分数，必须同时标明状态。

## 计时与资源

Linux x86_64云CPU、AMD EPYC 9V74；ONNX Runtime intra/inter各1，OpenCV/BLAS各1，识别batch6，固定legacy分类器与0.5结果过滤。线程参数不证明宿主机物理独占，cgroup配额不可见。这不是浏览器WASM或用户M4的实测。

每组新进程加载模型，初始化和等锁单列。每图单遍记录读取/OCR/结果提取的实际墙钟及队列时间；不能称为三次暖均值，也不能把此前批量吞吐的每页平均混进本轮单页时间。首张有冷执行影响，其余虽已加载模型也不称重复热测。模型文件字节数与进程RSS分别报告。

每组开始要求MemAvailable至少6GiB；运行时低于1.5GiB、同时协调器＋worker采样RSS超过5GiB或单图180秒则停止该组并保留partial，继续其他组，不偷偷降低分辨率。100ms采样可能漏瞬时峰，共享页可能重复计，不能当作精确最低物理内存需求。各组共用同一推理锁串行执行，组边界释放用于独立验证。

10张小样本、单遍耗时不足以估计泛化精度或统计显著性。检测参数是预先指定的敏感性实验，不因得到更低CER就可称普遍最优。最终结果供用户选择，不修改产品默认、不合并main。
