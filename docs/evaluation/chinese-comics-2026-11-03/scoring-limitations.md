# 评分实现独立审查

测试：`python3 -m unittest discover -s tests -p test_comic_benchmark_metrics.py -v`，21项全部通过（2026-11-03）。测试使用自造最小样例，不使用真实漫画转写。

## 已修复
- 全集无certain非空参考时macroCER原会除零，现返回null；空GT同样处理。
- 增加辅助去标点S/D/I/N与micro CER，便于复核分母及聚合。
- 对非有限、非正面积、负原点、越界bbox和重复image ID显式报错，避免静默除零或覆盖。
- 修正weakOverlapTargetCount注释：它是任一单框的包含关系诊断，不是联合面积覆盖/网格近似。小行框落在大段落内即可能计数，不能称该段落完整检出。

## 经测试确认
- Levenshtein S/D/I回溯优先匹配/替换、删除、插入；等长交换可能记为两个替换。分解在最小距离平局下不是唯一答案，固定规则对所有方案一致。
- 空输出、缺失图、失败无输出均保留GT字符分母并记全文删除；CER允许大于1。
- IoU使用最大基数一对一增广路匹配，而非简单贪心；不保证最大总IoU。用于TP数量时满足本实现目标。
- partial页面不报告FP/precision/F1，也不将未匹配预测全文算插入；仍报告对已标目标的召回。
- uncertain文本块不入CER，但框仍作为检测目标；分配到uncertain框的文字不评分。
- ignoreRegions按预测框至少50%面积落入忽略区时移除。应确保GT忽略区边界没有无意遮蔽目标。

## 重要解释边界
- 主CER是“几何分组后的端到端CER”，不是纯识别字符错误率。整图一个大段落横跨多个GT气泡时，只会分给一个GT（预测面积交集>=0.5）；其余GT可能被记漏字，大段落也可能全未匹配。分组失败会增加CER。
- 同一GT内多个行框按y/x拼接，竖排按x从右到左/y排序。固定规则不读取预测文字，避免挑有利匹配；但同一行高度抖动、跨列、漫画非标准阅读顺序仍可导致字符顺序错误。应另用固定GT裁剪比较纯OCR能力。
- 严格IoU将行级DB框与段落级GT直接比较，存在明确粒度惩罚。测试中一个正确短行落在段落内，CER可为0而IoU0.5 TP为0。不得据此声称行级检测器更差；应标为粒度敏感诊断，或在未来先冻结无文本聚合规则再评。
- NFKC会把全角标点/拉丁字符折叠，省略号“…”变成三个点；主CER保留折叠后的标点、大小写、繁简差异。辅助CER只去Unicode P*标点，不是“纯汉字CER”，符号类仍保留。
- confidence是模型内置信值，不能替代准确率；本评分不按置信度挑匹配或当作质量分数。
- 全部结果只代表固定10张便利样本，GT来自助手视觉转写而非专业双盲人工基准。
