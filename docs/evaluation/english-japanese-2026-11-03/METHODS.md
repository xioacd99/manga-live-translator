# 方法与阅读边界

## 不把“有输出”当“识别正确”

先固定样本原始字节与 SHA256，再独立目检、标注对白/旁白框和可确定的转写；不使用候选 OCR 输出填参考答案。不确定文字单独标记，不进入 CER 分母。密集历史手写页面若只完成部分标注，必须说明覆盖范围：该页结果是**已标注目标子集的错误率**，不是全页错误率；未标注部分的输出不能冒充误检。

英文、日文分别统计，不能因为语言集难度不同而把数字直接解释为模型的跨语言能力排名。历史英文手写与现代日文印刷也不是同分布测试。小规模助手标注和独立抽查不等于专业双盲金标。

## 共同方案与语言差别

- A：PP-OCRv5 mobile 全图 DB 检测、方向分类和识别，通过 RapidOCR / ONNX Runtime CPU 运行。官方识别模型卡明确涵盖中、英、日；本次继续相同权重，不以宣传指标替代实测。
- B：Tesseract best 全图 PSM11，完全无文本才重试 PSM3。英文使用 eng，日文使用 jpn。
- C：产品 RT-DETR 选择区域、原坐标外扩4像素、放大2倍，再 Tesseract PSM6；区域选择失败时沿用预先固定的全图回退。不同语言使用相应语言包。
- D：相同 RT-DETR 区域直接送 PP-OCRv5 识别器。它不是推荐的段落接口：多行段落与行识别器可能不匹配，作为既有管线对照保留。
- E：相同 RT-DETR 区域内再次运行 Paddle DB+识别。没有检测区域时该固定实验不私自加新回退。
- C-v（日文补充）：相同检测和裁剪，改用 jpn_vert + PSM5。固定竖排假设，不按 GT 逐框择优，横排可能退化。

Paddle 的 DB 管线会处理高宽比达到阈值的行裁剪旋转及0/180度分类；D直接段落识别没有同一几何步骤。因此“同权重”不表示同一输入接口或完全支持复杂多列竖排。

RT-DETR 使用产品的区域/图像预算，触发预算拒绝是实际结果，不为了测试页增加上限。各路线的回退差别必须与逐图数据一起解释。

## 错字、漏字、插字和词错误

主 CER = (替换 S + 删除 D + 插入 I) / 参考字符 N。NFKC 标准化后删除所有 Unicode 空白，保留大小写、标点和文字体系；繁简不转换、不用同义词放宽。辅助去标点 CER 只额外删除 Unicode P* 类别。CER 因插入可以超过100%，不截断成100%，也不称为“准确率”。

英文 WER 使用 NFKC 后按 Unicode 空白拆词，保留大小写和标点；不同预测框按几何顺序用一个空格连接。日文没有预先选定分词器，不提供假的 WER，返回 null。若同一英文单词/标点被拆成多个预测框，额外空格可能增加WER；这是严格区域切分口径，不是纯字形识别或词语义准确率。

所有文字配对只看框几何：预测框至少50%面积落入一个参考目标才归给它；每个预测只归一次。漏掉的已标目标算完整删除。仅全标页面才把目标外、非忽略区的输出算插入；部分标注页面的额外输出不评分。因此部分标注结果不能用于声称全页假阳性率。

现代日文主参考只统计正文基本文字，不转写振假名和强调点；能独立定位的小注音标忽略区，但混入同一识别框的额外假名仍可能作为插入计分。日文样本主要为竖排，不宣称覆盖现代横排对白。

本次显式采用 `--text-order line-column-overlap-v2`：水平同行按几何垂直重叠聚类再按 x 排序，避免词框 y 的轻微偏移打乱一句话；CER/WER共用版本。竖排采用对称的固定锚点列聚类，列从右到左、列内从上到下；保留旧v1结果用于敏感性对照。这不是完整漫画阅读顺序模型，混合行框/段落框、斜排、多列仍有局限。历史中文报告保留原算法，不悄悄覆盖它的数值。

## 检测分数的粒度

IoU阈值0.5为主、0.3为辅助，使用最大匹配数而非基于文字内容匹配。只有完整标注页能给精确率/F1；部分标注页只能报告已标目标的匹配/漏检。Paddle DB是行框，RT-DETR是文本段落/气泡相关框，同一段落GT下的严格IoU不适合直接给二者排名。Tesseract整图方案只有OCR词框，不伪装成独立对象检测器。

## 耗时是什么

云端 Linux CPU，单线程，共享互斥锁确保候选推理不重叠。每图首次处理与两次暖处理分开记录；初始化另计。首次处理第二张图不等于全模型冷启动，未清操作系统文件页缓存。

A/B完整调用是实际墙钟耗时。检测先单独测量，再测裁剪/识别的组合路线，其总数是**分阶段时间相加**，不是浏览器一体化管线墙钟耗时；图表明确加星号。没有测Mac M4、浏览器WASM/WebGPU、网页网络或LLM翻译，不能用本数字承诺最终产品延迟。
