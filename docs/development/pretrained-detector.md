# 本地预训练漫画区域检测

更新：2026-11-03（Asia/Shanghai）。dev 预览实现，尚未发布；不是质量或设备性能验收结论。

## 使用与网络边界

在扩展弹窗点击“下载并准备模型”，首次从固定 Hugging Face 地址下载 11,120,765 字节（约 11.1 MB）的检测权重。进度区区分下载、校验、加载和就绪；仅完整校验通过的模型写入扩展 IndexedDB，之后复用本地缓存。未完成下载不保存为可用模型。可以取消、失败后重试；关闭弹窗不等于取消后台下载。模型就绪后再次启用当前页面。

运行时代码和 WASM 随扩展打包，检测权重不放入安装包。下载步骤没有漫画图片或对白上传，不需要翻译 API 密钥；Hugging Face 及其分发基础设施仍会收到普通下载连接信息。下载地址、版本、大小与 SHA-256 固定在扩展内，网页不能指定任意模型、路径或下载目标。

模型缓存与阅读内容缓存不同：清除阅读缓存、清除翻译密钥或切换翻译账户不删除通用权重。它不包含用户图片、对白或密钥。阅读内容仍只保存在有期限、有容量限制的内存缓存。浏览器清理扩展存储或卸载可能移除权重，届时需要重新下载。没有实现断点续传；取消后重试可复用已完整校验的缓存，否则重新下载。

缺失、损坏、校验或加载失败不会伪装成“训练模型没有检出”，也不会自动隐藏为整图成功；区域模式要求模型就绪。用户可显式选择整图 OCR 绕过检测模型。翻译仍只在原有文本传输授权下发送文本到 OpenAI，可能计费。

## 实际算法和资源上限

`extension/adapters/pretrained-regions.js` 使用本地 CPU/WASM，单会话、单线程、串行推理，不启用 WebGPU。当前模型的 MaxPool ceil 属性不适用于已验证的 WebGPU 路径；不能将本实现称作 GPU 加速。Apple M4 尚未实测。

每块直接缩放到 640×640，不使用 letterbox；RGB 除以 255，Float32 NCHW `[1,3,640,640]`。`orig_target_sizes` 为 int64 `[width,height]`。输出为 300 个查询的类别、置信分数和原分块坐标 xyxy。类别为 0 气泡、1 气泡内文字、2 气泡外文字，接受阈值为 0.3。

优先裁剪文字框；有匹配文字的气泡不再重复 OCR，只有无匹配文字的气泡才作为候选。重叠候选去重，置信度保留模型实际输出，不再使用旧启发式固定 0.6。框按 y、再 x 排序不是经过训练的漫画阅读顺序，也没有像素级分割。

图片上限 4 MiB、16,000,000 像素；长宽比大于 2 的竖长图按约 1.5 倍图宽分块、约 20% 重叠，最多 16 块并恢复原图偏移。超出分块预算明确报错，不悄悄漏掉尾部；可改用显式整图 OCR。最多 32 个候选框，超额返回明确回退原因。候选框总 OCR 面积另受原图两倍的预算约束。

区域模式对有效候选执行局部 OCR；没有有效候选、区域预算超额或裁剪 OCR 低置信度等条件触发已有整图回退。有效局部结果不保证再做整图补漏，因此旁白、拟声词或漏检文字仍可能遗漏。整图 OCR 本身也可能漏字。用户可选择整图基线比较，不能声称区域方式一定更快或更准确。

WASM 推理不能强制抢占；取消请求需等当前 run 返回后再报告取消，之后不开始下一块。销毁等待在途操作再释放会话，成功、失败和取消均关闭位图。模型文件大小不是运行峰值内存，未测量浏览器峰值内存或 M4 p50/p95。

## 已观察结果及限制

在云端 Linux/x64、Node 24.22.1、真实 ONNX Runtime Web 1.23.2 WASM 和上述权重上，以原创合成图做接口验证：

- 旧 `HELLO WORLD` 矩形气泡样本未检出阈值以上候选。不能套用旧启发式的几何断言。
- 原创 800×1000、四气泡人物面板（`tests/fixtures/original-panel.png`）检出四个对白文字框，置信度约 0.902–0.915，另有一个人物脸部误检，置信度约 0.391。
- 适配器验证使用真实模型字节、真实 SHA-256 与真实 WASM 推理；Node 图像读取/缩放替身不等同浏览器 Canvas 端到端验证。上述观察不是有代表性的漫画 precision/recall 基准。

单元测试 `node --test tests/js/pretrained-regions.test.js` 覆盖实际输出形状、类别选择、恶意输出、边界坐标、分块偏移与去重、模型完整性、串行执行、取消和资源释放。多数单元测试使用可控会话替身，不能当作真实模型精度证据。浏览器测试与最终全量检查以当前提交的实际运行结果为准，不沿用历史 CI 代表新模型已验收。

真实授权漫画、多语言/竖排、彩色或不规则气泡、复杂分镜和阅读顺序、真实网站、设备内存与端到端延迟仍待评估。旧启发式评估保留为[历史对照](region-evaluation.md)，不代表当前检测器。

## 空 OCR 回退策略

真实云浏览器首轮测试发现，未检出框的带边框合成图使用 Tesseract 稀疏模式 PSM11 时输出空文本。真实本地复现后增加一次仅空结果触发的整图自动版面 PSM3 回退（不启用方向识别，也不新增模型），下一次请求仍从 PSM11 开始。该修复不能代表手写漫画质量改善，仍需逐样本验证。OCR 缓存身份使用 original-v2-empty-auto。
