# Issue #2：区域 OCR 与当前页面提前处理

此页描述 dev 实验性实现，不表示发布、真实漫画质量验收或 Issue 已关闭。

## 实际处理路径

- 当前使用预训练 RT-DETR 漫画气泡/文字框检测，CPU/WASM 本地推理。首次由用户在弹窗点击“下载并准备模型”，下载并校验约 11.1 MB 权重后缓存；运行时代码随扩展打包，检测权重不打包。来源、隐私、分块和许可见[预训练检测说明](pretrained-detector.md)。
- 默认区域模式优先文字框 OCR，文字框已覆盖的气泡不重复识别；无有效候选、区域预算超额或裁剪 OCR 低置信度等情况回到整图。成功的局部结果不保证整图补漏，可能遗漏旁白或拟声词，不宣称更准或更快。
- 模型缺失、损坏或加载失败明确提示，不伪装成零检测。区域模式须待模型就绪；用户可显式选择整图 OCR，无需下载检测模型。区域模式变动会失效对应 OCR 缓存。
- 当前仅打包英文 Tesseract。真实漫画、竖排和复杂阅读顺序仍需独立验证，不上传图片给 LLM。

旧亮色连通域及其指标仅保留为[历史对照](region-evaluation.md)，不代表当前训练模型。当前 WASM run 不能即时抢占，取消等待本次推理结束后生效。

## 用户操作和同意

进入网页不会新增处理。用户在扩展弹窗显式启用当前页面后，可分别选择：

1. 手动翻译，或已有的“可见图自动翻译”：OCR 文本发送至配置的 OpenAI 服务，可能计费。
2. 仅本地提前准备：默认关闭，开启后默认预算 8 张，可设置 1–20 张。不需要模型 API 密钥或 OpenAI 权限；只获取已授权图片并在本地检测/OCR，不发送翻译请求。
3. 远端提前翻译：默认关闭且预算 0；必须单独勾选并设置预算，再启用页面。仅发送文字，不上传原图；未读内容也可能计费。取消已经发送的请求不保证免计费。

设置、勾选和预算由可信弹窗写入会话授权。内容脚本不能自行增加预算或切换检测模式。预处理尝试在后台原子预扣预算，失败、取消和缓存命中也不退还，避免重试风暴；再次显式启用才重新授权一轮预算。可见自动与手动请求不算“远端预取”预算，仍受总并发/队列限制。

## 页面和资源范围

- 当前顶层文档内符合规则的静态 img/currentSrc，最多发现 80 张；不访问下一章/下一页，不强制触发尚未暴露图片源的懒加载，不递归扫描链接。
- 可见图优先，其次邻近视口，再处理本页已发现的其余图片。滚动会重新排序尚未启动的候选，不抢占正在进行的 OCR。
- reader 最多同时 2 个任务；后台全局最多 16 个任务，每张最多 4 MiB、1600 万像素，单任务 120 秒。检测每块缩放到 640×640，长图最多 16 个重叠块、最多 32 个候选框；检测与 OCR 各自串行。
- 检测、OCR、翻译三个结果缓存分别最多 128 项、8 MiB、30 分钟；默认只在扩展执行器内存中，无原图持久化。独立的 IndexedDB 权重缓存仅保存已验证通用模型，不保存阅读内容，清理阅读缓存/密钥不会删除它。检测运行时像素/队列占用与结果缓存分开，不能把 24 MiB 结果预算说成整个浏览器进程内存上限。
- 页面隐藏、暂停、关闭、导航、撤权或清理会取消任务。隐藏后必须重新启用，不自动恢复付费预取。清理同时暂停已授权页面，晚到结果不能填回缓存。
- 进程被终止会丢失内存缓存；没有跨崩溃严格一次调用保证。会话预算保存在可信 session 存储，但未知已发请求仍可能计费。

## 缓存与结果语义

检测键包含原始图像字节哈希、尺寸、授权源与检测版本/参数；OCR 键另包含实际区域几何、裁剪约定和识别配置；翻译键包含有效文字、语言、模型、术语及上下文。仅改变上下文复用检测/OCR，改变区域选择只失效受影响阶段。相同在途任务共享计算。

“本地已准备”不是“已翻译”。在相同账户/有效配置下，后续阅读可以复用准备结果；从未配置状态切换到真实账户会重建隔离流水线，不能承诺跨账户复用。源文字纠错仍以原始 OCR 为基底，仅重新翻译。

## 验证与指标

- `npm test` 覆盖区域映射、去重、低置信度回退、缓存失效、取消、授权、默认零远端预取、预算和页面生命周期。
- `npm run test:tooling` 校验开发/Issue 工具；`npm run build` 构建全部本地 OCR 资产。
- `npm run test:browser` 使用真实 Chromium、打包的 OCR 和自制图片，但图片获取与 LLM 是受控 mock，禁止真实付费或用户漫画输入。执行成功必须以当前提交 CI 结果为准。
- `node benchmarks/preparation.mjs` 对同一 12 张/实际阅读 8 张的人工工作负载比较关闭预取、纯本地准备、远端准备。见 [合成测量原始结果](evidence/preparation-synthetic.json)。固定延迟替身仅用于验证调用/缓存口径，不代表真实等待收益或 M4 性能。
- 有用预取率是实际阅读的已准备图数/全部准备图数；本样本为 8/12。纯本地准备新增 0 个 LLM 预取调用；远端准备会为未读的 4 张付出额外请求。不要只展示升高的缓存命中率。
- 各层命中率分母是该层 Lookups，Coalesced 单独统计。Provider 提示缓存不在本实现测量范围。真实漫画误检/漏检、实际浏览器峰值内存、冷启动、M4 与真实服务费用/质量仍未验收。
