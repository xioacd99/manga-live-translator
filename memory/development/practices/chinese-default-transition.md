# 中文默认规范与 Issue 迁移边界

- 状态：当前规范已调整；线上 main 模板切换仍等待明确合并授权。
- 更新日期：2026-11-03（Asia/Shanghai）。
- 范围：开发规范、文档、代码注释、Issue 表单与共享结构检查。

## 背景与决策

项目维护者明确将后续开发、代码注释及 Issue 默认语言从英文改为中文，将来需要英文时另维护英文文档。当前 README、MEMORY、AGENTS 和使用指南转为中文，新记录与模板使用中文。既有英文研究材料、历史更新与第三方许可证不做机械批量翻译；技术标识与运行时输入语言保持独立。

## 已确认的平台边界

仓库默认分支仍为 main，现有 Issue standards 工作流明确检出 refs/heads/main。仅更新 dev 的模板和校验器，不会自动切换 GitHub 新建 Issue 页面或 main 工作流；本次不合并 main、不修改旧 Issue。

新校验器需兼容历史英文 Issue。过渡期实际提交使用旧版可识别的 [Feature] 前缀与英文结构标题，题目和正文为中文，同一字段只出现一次，不通过重复双语段落规避检查。结构检查不能替代真实性、权限、查重与敏感信息审核。

## 验证要求

运行中文与历史英文结构回归、中文命令行用例及恶意输入测试，并核验实际新 Issue 同时通过 main 和 dev 校验器。默认语言变化不代表气泡检测、整页预处理或真实翻译质量已经实现。
