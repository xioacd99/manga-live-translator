# Paddle英文型号比较经验

- 状态：resolved（本轮评测完成，产品方案待选择）。日期：2026-11-03，Asia/Shanghai。
- 来源：[图文报告](../../../docs/evaluation/paddle-english-models-2026-11-03/README.md)、[方法](../../../docs/evaluation/paddle-english-models-2026-11-03/METHODS.md)。
- 原英文输入和冻结GT均按SHA完整恢复后复用。共享执行目录不能作为唯一备份；公开仓库只留许可合适的图表和非全文证据，原图/GT/预测在私有评测备份中保留。
- RapidOCR版本升级与模型变化须分离：同v5权重在3.4.5和3.10.0的框/文字/识别分数一致，CER精确复现；耗时仪器和环境变化时必须全组重跑。
- RapidAI有意选定的检测归一化/DB参数与百度官方不同，不是单凭模型名字就能代表官方流水线。预先指定small同权重参数对照，结果指标各有改善和退步，不能只挑最好一个分数。
- 捕获原始DB分数时发现框排序可能未同步分数；禁止用该字段解释单框质量。无几何匹配输出、字符删除、整页漏检是不同概念。
- 本轮small更适合作为下一步浏览器候选，medium更准确但云CPU更慢且权重更大；这些不是M4/浏览器测量，也不是翻译质量结论。未修改默认模型、合并main或发布。
