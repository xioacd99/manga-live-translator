- 状态：open，模型集成已实现，真实漫画质量与云浏览器验收分别记录，不等于发布。
- 日期：2026-11-03（Asia/Shanghai）。
- 关联：[Issue #2](https://github.com/xioacd99/manga-live-translator/issues/2)。

## 纠正与选择

前一版先实现亮色连通域启发式，没有先充分比较已有漫画检测实现，不能满足以已训练对象检测模型为基础的需求。该启发式保留为历史对照，不再是默认检测路径。当前独立实现使用 Apache-2.0 标注的 ogkalu 漫画 RT-DETR ONNX 模型，WASM 在运行浏览器的电脑上推理；未复制 ImageTrans 的 GPL 代码。

模型固定 revision、11,120,765 字节和 SHA256。运行时代码与 WASM 随扩展打包，权重首次由用户触发从固定 Hugging Face 地址下载。只缓存完整且校验通过的权重，IndexedDB 事务提交后才成为可复用记录；中断重试从头开始，不声称断点续传。无 Content-Length 时展示已下载字节，不伪造百分比。模型服务器仅接收模型 GET，不接收漫画图或 OCR 内容。

## 已复现问题与修复

- 缓存检查尚未结束时点击下载，不能丢掉明确用户意图。协调层记录待启动下载；取消或撤权同时清理该意图。
- WASM 正在推理时不能立即抢占。检测与模型加载由跨账号流水线共享的队列串行，取消阻止后续阶段，不谎称瞬间停止计算。
- 检测权重读取和 ONNX session 初始化是不同阶段。界面只有在 session 初始化完成后才展示就绪。
- 模型缺失、损坏或加载错误不静默降级掩盖问题。用户可以明确选择整图 OCR；有效框路径为局部 OCR，零框或局部识别低置信的回退按 OCR 适配器执行，不保证每次整图补漏。

## 真实验证边界

云 Linux CPU 上，官方原始模型经 SHA256 验证，并使用真实 ORT WASM 对原创四气泡图推理，得到四个对白区和一个低分脸部误检；旧单一矩形 HELLO WORLD 合成图没有超过阈值的检测。这是可重复的集成证据，不是漫画准确率，也不是 Mac M4 性能。具体模型来源、许可证、输入输出与阈值见当前开发文档。浏览器测试使用官方真实权重但模拟下载流和 LLM，需查看该提交 CI 结果，不能把测试网络模拟说成真实站点访问。

单元测试覆盖缓存校验、并发、取消、缺失与配额错误，以及首次检查竞争、就绪门禁、可信发送方与跨账号推理串行。真实十图质量评估是单独工作，未完成前不得写入结果。
